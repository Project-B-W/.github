# Black & White Hacker

> 당신이 해커가 되어, 비밀번호가 얼마나 쉽게 뚫리는지 직접 겪는 게임.

**실시간 전략 · 퍼즐 · 심리 / PC / 4인 멀티플레이**

위험한 다운로드와 단순한 비밀번호가 개인정보 유출로 이어지는 과정을
플레이어가 직접 체험하도록 설계한 멀티플레이 전략 게임입니다.

## Core Mechanics

- 파일의 가치·용량·위험도를 고려한 자원 수집
- 흑백 비밀번호 추론을 통한 상대 해킹
- 점수 획득과 보안/해킹 업그레이드 사이의 자원 선택
- 점수승 또는 상대 개인정보 전부 탈취를 통한 KO승
